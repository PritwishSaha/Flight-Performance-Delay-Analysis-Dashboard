## 📌 Project Overview
The **Flight Performance & Delay Analysis Dashboard** is an interactive Power BI project designed to analyze flight operations, delays, and airline performance trends. The dataset was cleaned using **Microsoft Excel** and transformed into an insightful, interactive dashboard in **Power BI**.

The dashboard helps identify airline-wise flight volume, delay patterns, market share, and daily flight trends that support operational and business decision-making.

## 📌 Key Insights
- ✈️ Total Flights: **134K**
- 🛫 Average Departure Delay: **-0.56 minutes**
- 🛬 Average Arrival Delay: **-7.43 minutes**
- 📏 Average Flight Distance: **727.62 miles**
- 🏆 A small set of airlines (AA, DL, UA, WN, AS) account for the majority of market share
- 📅 Daily flight volume shows recurring peaks and dips, indicating weekly travel patterns
- ⏱ On average, flights arrive earlier than scheduled, suggesting strong overall on-time performance
